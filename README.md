# DCX proximity proteomics

Analysis code associated with the manuscript:
### “DCX mutation selectively disrupts lattice-dependent proximity to reveal functional cytoskeletal networks in developing neurons”

Analysis and plotting code is provided as Jupyter notebooks organized by manuscript figure and analysis type. Notebook outputs have been retained to display the resulting plots.

#### Repository contents
Figure 1 (main and supplementary): Normalization and plotting of fluorescence-intensity profiles measured along neurites across biological replicates.

Figures 2 and 4 (supplementary): Generation of replicate-clustering heatmaps and principal component analysis plots from matrices exported from Perseus.

Figure 3 (main and supplementary): Generation of protein-family heatmaps and temporal line plots, as detailed in the notebook documentation.

Figure 5 (main and supplementary): Multiple-sequence alignment, peptide mapping, and peptide-detection analyses for proteins identified as differentially enriched in Figure 4.

Figure 6 (main and supplementary): Normalization and plotting of fluorescence-intensity profiles measured along neurites, growth cones, and branch sites.

#### Statistical analysis
Proteomics filtering and statistical analyses were performed in Perseus. The associated Perseus workflows, statistical matrices, and exported input files are provided as supplementary files accompanying the manuscript.

#### Data availability
The mass-spectrometry proteomics data have been deposited to the ProteomeXchange Consortium via the PRIDE partner repository with the dataset identifier PXD083262.
